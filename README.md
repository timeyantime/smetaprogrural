# СметаПро — сметная программа ресурсного метода

Локальное веб-приложение для составления локальных смет ресурсным методом на **Alpine.js** (без сборки, без сервера).
Полное описание модели данных и столбцов — в [docs/SPEC.md](docs/SPEC.md).

## Запуск

```bash
python3 -m http.server 8080   # или любой статический сервер
# открыть http://localhost:8080
```

## Возможности

- Таблица ресурсов в стиле Airtable: вкладки-разделы, inline-редактирование, чипы типов затрат (ЗТ / ОМ / М + Тмр), группировка, сортировка, выделение записей;
- **Изменение ширины столбцов** перетаскиванием границы заголовка (сохраняется в браузере; сброс — в меню колонки ▾);
- Каскадный расчёт: стоимость строки → раздел → ПЗ → НР → СП → НДС → Итого (выбор базы НР/СП: от ФОТ или от ПЗ);
- Диаграмма Ганта: длительность задаётся в столбце «Длит., дн.»; записи с длительностью **0 или пустой на диаграмму не попадают**; сводные полосы разделов; учёт активной вкладки раздела;
- **НСБ** — нормативно-справочная база расценок: добавление/редактирование/удаление, импорт/экспорт JSON, вставка расценки в смету, массовое обновление цен выделенных записей;
- **Справочник** — подробная методика расчёта затрат прямо в приложении (кнопка вверху);
- Печать с выбором ориентации: **альбомная / книжная** (печатается текущий вид — таблица или Гант);
- Автосохранение в localStorage, ручное «💾 Сохранить», экспорт/импорт JSON, экспорт CSV.

## ⛔ Канбан — запрещён к разработке

**Канбан-доску реализывать НЕЛЬЗЯ.** Это решение окончательное: никаких досок, колонок «To do / In progress / Done», drag-and-drop карточек между статусами и подобных интерфейсов в этом проекте быть не должно. Планирование работ выражается исключительно через диаграмму Ганта и разделы сметы.

## Структура

```
index.html      — интерфейс (Alpine-разметка)
js/app.js       — модель smeta(): данные, расчёты, Гант, НСБ, печать
js/money.js     — директива x-money (денежное форматирование)
css/style.css   — стили Airtable-style + печатные правила
docs/SPEC.md    — спецификация: столбцы, формулы, модель данных
```
